# icloud-mail-checker

Maintainer: lmerega. Chrome MV3 extension for iCloud Mail, modeled on proton-mail-checker.
All iCloud endpoint details are isolated in background/constants.js and background/icloud-api.js
(private, unverified API). Run `npm test`. Use synthetic data and .invalid domains; never commit
credentials, cookies or real mail. No Claude/assistant attribution in commits or PRs.
