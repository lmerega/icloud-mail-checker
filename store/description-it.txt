Zoho Mail Checker porta Zoho Mail nella barra di Chrome.

• Badge dei non letti, notifiche desktop e suono facoltativo quando arriva una mail
• Posta, Archivio, Inviata e Cestino con ricerca; svuota il cestino con un clic
• Leggi i messaggi nel popup, con immagini remote e tracker bloccati
• Segna letto/non letto, preferiti, archivia ed elimina dal popup o con i pulsanti al passaggio del mouse
• Passa al messaggio precedente o successivo senza tornare all'elenco
• Rispondi in HTML alle mail HTML con l'editor integrato, o scrivi un nuovo messaggio
• Codici di verifica riconosciuti e copiati con un clic
• Tema chiaro, scuro o automatico; italiano e inglese; esporta/importa impostazioni

Riservata per costruzione: l'estensione parla solo con le API ufficiali di Zoho Mail, con un client OAuth che crei tu nella API Console (gratis, circa 2 minuti, guida passo passo nelle opzioni). La tua password non viene mai vista; Client Secret e token restano nel tuo browser. Non esiste un server dello sviluppatore: lo sviluppatore non riceve nulla. Funziona con tutti i data center.
