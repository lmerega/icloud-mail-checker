Zoho Mail Checker puts your Zoho Mail in the Chrome toolbar.

• Unread badge, desktop notifications and an optional sound when new mail arrives
• Inbox, Archive, Sent and Trash with search; empty the trash in one click
• Read messages in the popup, with remote images and trackers blocked
• Mark read/unread, star, archive and delete from the popup or with hover buttons
• Go to the previous or next message without going back to the list
• Reply in HTML to HTML mail with an inline editor, or write a new message
• Verification codes detected and copied in one click
• Light, dark or automatic theme; English and Italian; settings export/import

Private by design: the extension talks only to Zoho, through the official Zoho Mail API, with an OAuth client you create yourself in the Zoho API Console (free, about 2 minutes, step-by-step guide in the options). Your password is never seen; Client Secret and tokens stay in your browser. There is no developer server: the developer receives nothing.

Works with every Zoho data center (zoho.com, zoho.eu, zoho.in, zoho.com.au, zoho.jp, zohocloud.ca, zoho.sa, zoho.uk, zoho.com.cn).
