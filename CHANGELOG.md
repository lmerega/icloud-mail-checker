# Changelog

## 2.0.0 - unreleased

Now for Zoho Mail instead of iCloud Mail (iCloud support removed).

- Official Zoho Mail REST API with OAuth 2.0 and the user's own API Console client; sign-in from the options page.
- All Zoho data centers; fixed extension ID so the OAuth redirect URI is stable.
- Same popup and features; messages shown one by one; archive moves to an "Archive" folder.

## 1.0.0 - 2026-11-27

First stable release.

- Unread badge, desktop notifications, optional sound (six sounds, test button).
- Popup in a Material style with light/dark/automatic theme, folders, search and open in a tab.
- Whole conversations, sanitized rendering (no remote content), previous/next message.
- Mark read/unread, star, archive, delete, empty the trash.
- HTML replies with an inline editor and quoted original; new messages.
- Verification-code detection; open iCloud Mail from toolbar, shortcut or notification.
- Settings export/import; English and Italian.
